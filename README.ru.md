## Что такое KiPaint

KiPaint — свободный редактор с открытым исходным кодом, нацеленный на одну вещь: **ощущение рисования как в Clip Studio Paint, но без платных тарифов и закрытого кода.** Он построен на движке [Graphite](https://github.com/GraphiteEditor/Graphite) (Apache-2.0): сохраняет его нодовое ядро, GPU-рендер и CRDT-модель документа, но заменяет ориентированный на дизайнеров интерфейс и набор инструментов рабочим процессом для художников — иллюстраторов, авторов комиксов и манги.

Фокус не в том, чтобы заново изобрести графический движок, а в том, чтобы довести до ума то, чем художник пользуется каждый день: естественный движок кистей с динамикой нажима и стабилизацией линий, растровые слои с клиппинг-масками, заливка, которая просто работает, векторное редактирование линий, таймлайн анимации и панели комиксов — в нативном десктоп-приложении, которое ощущается как настоящий инструмент рисования, а не нодовый редактор с прикрученными кистями.

> *CLIP STUDIO PAINT — товарный знак Celsys, Inc. KiPaint — независимый open-source проект, не связанный с Celsys и не одобренный ею. Дизайн интерфейса и все ассеты оригинальны.*

## Статус

Проект в ранней стадии разработки. Сейчас в репозитории — импортированная база Graphite (ядро редактора, нодовый граф, десктоп-шелл, веб-фронтенд) с документацией KiPaint. Функциональная работа над KiPaint начинается сейчас — см. [дорожную карту](ROADMAP.md).

**Что уже работает (унаследовано от базы Graphite):**

| Область | Состояние |
|---|---|
| Нативный десктоп-шелл | Окно winit + wgpu, Windows / macOS / Linux |
| Ввод с планшета | Нажим, наклон, поворот, ластик пера через патченный форк winit |
| Движок кистей | GPU-кисть (супергауссово ядро): диаметр, жёсткость, поток, нажим → размер |
| Слои | Слои на нодовом графе, папки, 27+ режимов наложения, клиппинг-маски, прозрачность |
| Векторные инструменты | Перо, узлы, свободная линия, сплайн, фигуры, булевы операции |
| Растровая обработка | Уровни, кривые, тон/насыщенность, размытие, LUT (`.cube`, `.3dl`, `.csp`…) |
| Текст | Каталог шрифтов, правка на холсте, конвертация в кривые |
| Формат документа | CRDT-контейнер `.gdd` — undo, миграции и слияние из одного хранилища |
| UI-фреймворк | Svelte-фронтенд, докируемые панели, готовая инфраструктура локализации |

**Что добавит KiPaint (в планах):** стабилизация линий и кривые нажима, прозрачность и текстуры на уровне кисти, заливка и волшебная палочка с закрытием разрывов, раскладка панелей в духе CSP, палитра кистей с суб-инструментами, цветовой круг и смешивание, навигатор, таймлайн анимации с onion skin, инструменты правки векторных линий, линейки и перспектива, рамки комиксов и облачка, скринтоны, поддержка PSD. Подробности в [ROADMAP.md](ROADMAP.md).

## Сборка

Требования: Rust 1.98+, Node.js + npm, таргет `wasm32-unknown-unknown`, зафиксированные версии `wasm-bindgen-cli`, `wasm-opt`, `cargo-about` (бутстраппер `cargo run` ниже сам проверяет и устанавливает большую часть; для сборки CEF дополнительно нужны CMake + Ninja на Windows/macOS).

```bash
# первая сборка (скачивает брендинг, собирает wasm, бандлит десктоп-приложение)
cargo run --package cargo-run -- desktop

# или короче
cargo run -- desktop
```

Артефакты и бандлы собирает `graphite-desktop-bundle`; при первом запуске wasm-модуль фронтенда компилируется в `frontend/wrapper/pkg-native/`, а Svelte-фронтенд — в `frontend/dist/`.

Веб-сборка (WASM):

```bash
cargo run -- web
```

## Структура проекта

| Каталог | Содержимое |
|---|---|
| `desktop/` | Нативный десктоп-шелл: окно, композитинг, ввод, бандлинг, платформенный код (Linux / macOS / Windows) |
| `editor/` | Ядро редактора на Rust: система сообщений, инструменты, состояние документа и портфолио |
| `node-graph/` | Нодовый движок: компилятор графа, исполнитель, GPU-рантайм wgpu, ноды кисти, растра, вектора, наложения |
| `document/` | Формат документа и CRDT-хранилище (контейнер `.gdd`) |
| `frontend/` | Svelte/TypeScript UI (в CEF на десктопе, в браузере на вебе) |
| `tools/` | Инструменты разработки: бутстраппер `cargo-run`, драйверы CI, генераторы документации |
